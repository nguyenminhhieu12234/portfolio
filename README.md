# Portfolio — Nguyễn Minh Hiếu

Portfolio tĩnh cho vị trí **IT Business Analyst**, xây dựng từ nội dung `Phong-van-BA-Hieuver04.pptx`.

## Chạy website

- Cách nhanh nhất: mở trực tiếp `index.html` bằng trình duyệt.
- Khuyến nghị trong VS Code: dùng extension Live Server, chọn **Open with Live Server** tại `index.html`.
- Hoặc dùng Python: `python -m http.server 8000`, sau đó mở `http://localhost:8000`.

## Cấu trúc

- `index.html` — nội dung, SEO, semantic HTML.
- `styles.css` — giao diện responsive, dark editorial-tech.
- `script.js` — menu mobile, tabs accessible, animation, copy email.
- `assets/image1.png`, `assets/image2.png` — ảnh giao diện trích từ PowerPoint nguồn.

Không cần cài dependency hoặc build.
